1. ¿Qué es un repositorio? ¿Para qué sirve?
Es una recopilación de un proyecto entero: ficheros, versiones y un registro de actualizaciones.
Sirven para crear un flujo de trabajo seguro con copias, que además permite experimentar sin comprometer todo el proyecto.

2. ¿Qué es un commit? ¿Por qué son importantes los mensajes de commit?
Es una captura del estado de un proyecto en un momento concreto.
Son importantes porque nos dan información corta y concisa del estado del proyecto en ese instante capturado. 

3. ¿Qué diferencia hay entre Git y GitHub?
Mientras que Git es un programa que se ejecuta en local en nuestro ordenador, mientras que GitHub es una plataforma online donde subimos nuestros repositorios para poder compartirlos.

4. ¿Qué hace el comando git push? ¿Y git pull?
Con git push subes a GitHub tu repositorio mientras que con git pull lo recuperas de GitHub y lo fusionas en tu rama actual.
